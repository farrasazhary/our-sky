# Purpose

Dokumen ini menjadi pedoman utama dalam merancang antarmuka (UI) dan pengalaman pengguna (UX) pada aplikasi **OurSky**.

Seluruh halaman, komponen, ilustrasi, animasi, dan interaksi harus mengikuti guideline ini agar aplikasi memiliki identitas visual yang konsisten.

---

# Design Philosophy

OurSky dirancang sebagai aplikasi Relationship Journey.

Tujuan utama desain bukan hanya menampilkan informasi, tetapi juga menciptakan rasa:

* Hangat
* Tenang
* Intim
* Personal
* Romantis tanpa berlebihan

Setiap elemen visual harus membantu pengguna menikmati perjalanan Relationship bersama pasangan.

---

# Design Principles

## 1. Emotional First

Keputusan desain harus mempertimbangkan pengalaman emosional pengguna.

Interaksi sederhana lebih diutamakan daripada fitur yang kompleks.

---

## 2. Clean Interface

Gunakan tata letak yang sederhana.

Hindari elemen visual yang tidak memiliki fungsi.

---

## 3. Content Focused

Konten Relationship menjadi pusat perhatian.

UI hanya berperan sebagai pendukung.

---

## 4. Consistency

Komponen yang sama harus memiliki perilaku yang sama di seluruh aplikasi.

---

## 5. Accessibility

UI harus mudah digunakan oleh seluruh pengguna.

Perhatikan:

* Kontras warna
* Ukuran teks
* Ukuran tombol
* Area sentuh

---

# Visual Identity

Karakter visual OurSky adalah:

* Modern
* Soft
* Calm
* Minimalist
* Friendly

Hindari:

* Warna terlalu mencolok
* Efek berlebihan
* Animasi yang mengganggu
* Tampilan yang ramai

---

# Color System

## Primary

Digunakan pada aksi utama.

Contoh:

* Primary Button
* Active Navigation
* Progress

---

## Secondary

Digunakan sebagai pendukung.

---

## Background

Gunakan warna terang dan nyaman dipandang.

---

## Surface

Digunakan untuk:

* Card
* Dialog
* Bottom Sheet
* Modal

---

## Semantic Colors

Gunakan warna khusus untuk:

* Success
* Warning
* Error
* Information

---

# Typography

Gunakan maksimal tiga tingkatan.

## Heading

Untuk judul halaman.

---

## Title

Untuk judul section.

---

## Body

Untuk isi utama.

---

Gunakan font yang:

* Mudah dibaca
* Modern
* Konsisten

---

# Spacing System

Gunakan sistem spacing yang konsisten.

Contoh:

* XS
* S
* M
* L
* XL

Semua margin dan padding mengikuti sistem ini.

---

# Border Radius

Gunakan radius yang konsisten.

Contoh penggunaan:

* Button
* Card
* Input
* Dialog

---

# Shadows

Shadow digunakan seperlunya.

Prioritas:

* Card
* Floating Button
* Modal

Hindari shadow yang terlalu tebal.

---

# Icons

Gunakan ikon yang:

* Sederhana
* Rounded
* Konsisten

Ikon digunakan untuk memperjelas informasi, bukan sebagai dekorasi.

---

# Illustration

Ilustrasi digunakan pada:

* Empty State
* Onboarding
* Error State
* Success State

Gunakan gaya ilustrasi yang:

* Soft
* Minimal
* Flat
* Friendly

---

# Images

Gunakan gambar dengan kualitas tinggi.

Foto pasangan menjadi fokus utama.

Pastikan:

* Tidak terpotong secara ekstrem.
* Mendukung berbagai ukuran layar.
* Tetap proporsional.

---

# Components

Komponen utama:

* Button
* Input
* Card
* Chip
* Badge
* Dialog
* Bottom Sheet
* Navigation Bar
* App Bar
* Floating Action Button

Semua komponen harus mengikuti Design System.

---

# Animations

Animasi harus memiliki tujuan.

Gunakan animasi untuk:

* Page Transition
* Success
* Celebration
* Opening Time Capsule
* Opening Open When
* Constellation Interaction

Animasi harus:

* Halus
* Cepat
* Tidak mengganggu

---

# Empty States

Setiap fitur harus memiliki Empty State.

Empty State harus:

* Menjelaskan kondisi.
* Memberikan tindakan berikutnya.
* Menggunakan ilustrasi sederhana.

---

# Loading States

Gunakan Skeleton Loading apabila memungkinkan.

Hindari Loading Screen yang terlalu lama.

---

# Error States

Error harus:

* Mudah dipahami.
* Tidak menyalahkan pengguna.
* Memberikan solusi.

Contoh:

"Connection lost.

Please try again."

---

# Responsive Design

UI harus mendukung:

* Mobile Phone
* Tablet
* Desktop (Future)

Prioritas utama adalah Mobile.

---

# Dark Mode

Dark Mode harus:

* Nyaman digunakan pada malam hari.
* Menjaga kontras.
* Mengurangi cahaya berlebihan.

---

# Accessibility

Minimal mendukung:

* Screen Reader
* Keyboard Navigation (Web)
* High Contrast
* Dynamic Text Size

---

# Design Consistency Checklist

Sebelum halaman dirilis, pastikan:

* Menggunakan komponen Design System.
* Mengikuti Color System.
* Menggunakan Typography yang benar.
* Mengikuti Spacing System.
* Memiliki Empty State.
* Memiliki Loading State.
* Memiliki Error State.
* Mendukung Dark Mode.
